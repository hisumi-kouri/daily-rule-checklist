# 毎日のルールチェック v0.4

Supabaseアカウント同期を整理した版です。

## v0.4の変更
- ログイン済み画面に「パスワードを更新」を追加
- パスワード再設定メールを追加
- ログイン済みなのにログインフォームが表示され続ける問題を解消
- 日本時間のローカル日付で日次チェックを保存
- PC・スマホで同じメールアカウントを使う前提のUIに整理

Supabase公式では、匿名ユーザーを永続ユーザーへ変換する際、メール確認後に `updateUser({ password })` でパスワードを設定できます。パスワード再設定は `resetPasswordForEmail()` から開始できます。


## 追加機能
- ユーザーが追加したルールは、各ルール右側の「削除」ボタンから削除できます。
- 初期登録されているルールは削除できません。
