# 毎日のルールチェック v0.54

Supabaseアカウント同期を整理した版です。

## v0.54の変更
- 報告書と医療共有用PDFを、呟き・補足を混在させた日付の古い順に変更

## v0.53の変更
- 起動時に「今日のスケジュール」を最初に表示
- 予定の表示は当日に固定して開始。必要に応じて「これから」「すべて」へ切り替え可能

## v0.52の変更
- 睡眠時間を「○時間○分」と数値で読み取れる表示に改善
- その他パラメーターの補足を、薄い紫の報告カードとして報告書・医療共有用PDFへ自動反映

## v0.51の変更
- 心の状態の推移を、全6項目を色分けした折れ線グラフへ変更
- グラフ上の点に日付・項目・数値を表示し、医療共有用PDFにも反映

## v0.50の変更
- 「今日のチェックシート」からは独立した、スケジュール専用タブを復旧
- 日付・時刻・予定・メモを登録し、当日・これから・すべてで見やすく表示
- 完了チェック、変更、削除に対応。端末保存とクラウド同期の両方に対応

## v0.49の変更
- ログイン済み画面に「パスワードを更新」を追加
- パスワード再設定メールを追加
- ログイン済みなのにログインフォームが表示され続ける問題を解消
- 日本時間のローカル日付で日次チェックを保存
- PC・スマホで同じメールアカウントを使う前提のUIに整理

Supabase公式では、匿名ユーザーを永続ユーザーへ変換する際、メール確認後に `updateUser({ password })` でパスワードを設定できます。パスワード再設定は `resetPasswordForEmail()` から開始できます。


## 追加機能
- ユーザーが追加したルールは、各ルール右側の「削除」ボタンから削除できます。
- 初期登録されているルールは削除できません。


## v0.9 変更点
- 服薬管理を追加
- 薬名・用量・服用タイミング・メモを登録可能
- 服用済みを日付ごとにチェック・同期
- 服薬の変更・削除に対応
