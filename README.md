# 毎日のルールチェック v0.50

Supabaseアカウント同期を整理した版です。

## v0.50の変更
- ログイン済み画面に「パスワードを更新」を追加
- パスワード再設定メールを追加
- ログイン済みなのにログインフォームが表示され続ける問題を解消
- 日本時間のローカル日付で日次チェックを保存
- PC・スマホで同じメールアカウントを使う前提のUIに整理

Supabase公式では、匿名ユーザーを永続ユーザーへ変換する際、メール確認後に `updateUser({ password })` でパスワードを設定できます。パスワード再設定は `resetPasswordForEmail()` から開始できます。


## 追加機能
- ユーザーが追加したルールは、各ルール右側の「削除」ボタンから削除できます。
- 初期登録されているルールは削除できません。


## v0.9 変更点
- 服薬管理を追加
- 薬名・用量・服用タイミング・メモを登録可能
- 服用済みを日付ごとにチェック・同期
- 服薬の変更・削除に対応


## v0.52 変更点
- 「心の状態の推移」を棒グラフから折れ線グラフへ変更。0〜10の推移を日付ごとに確認しやすくしました。
- 「睡眠時間の推移」を「7時間30分」のような時・分表示に変更しました。


### v0.52 追加
- その他パラメーターの「補足」を薄い紫色で表示。
- 入力された補足は30日分を報告書へ必ず掲載。
- 医療共有用PDFにも補足を掲載。


## v0.52.2変更点
- 「呟き（murmur）」「趣味（hobby）」「読書（reading）」を画面から削除。
- スケジュールは「スケジュール」欄だけで管理。チェックシート等には表示しない。
- 報告は「その他パラメーターの補足」を必ず掲載する構成を維持。


## v0.52.3
- 「呟き」「趣味」「読書」を専用タブとして復旧。
- これらは今日のチェックシートには表示しない。
- スケジュールは「スケジュール」タブのみで管理。
- 報告書・医療共有用PDFでは気分6以上の呟きとその他パラメーターの補足を引き続き表示。


## v0.52.4
- 呟き・趣味・読書の専用欄は維持し、それぞれのデータを専用カテゴリへ保存。
- 今日のチェックシートには、呟き・趣味・読書・スケジュールの項目を表示しないよう整理。
- 既存の呟き・趣味・読書データも専用欄から継続利用可能。
